# qa_java

Финальный проект 6 спринта: юнит-тесты для Feline, Cat и Lion.
Дополнительное задание — класс Alex и тесты для него.

Java 11, JUnit 4.13.2, Mockito 3.12.4, JaCoCo 0.8.7.

Запуск тестов и создание отчёта:

```bash
mvn clean verify
```

Отчёт о покрытии: `target/site/jacoco/index.html`.

Lion получает зависимость через интерфейс FelineBehavior в конструкторе.
Параметризованные тесты вынесены в отдельные классы.
